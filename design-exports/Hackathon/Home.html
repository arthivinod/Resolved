UX decisions, on the screen

Inline rationale lives in home-screen.jsx — search for // — UX:. This panel maps the brief's 7 questions to the picks I made.

1 · CTA specs

56pt · gradient · saffron glow
Top of the 52–56 range. Icon is a plus inside the label (gap 8) — outside arrows turn a CTA into a feature row.

2 · Stat-card affordance

Tappable → Cases
Whole-card target. Affordance: corner chevron + scale(0.99) press state. Never a second filled button — that would break the CTA-centric rule.

3 · Empty state

Community stats, always
Stat values are platform-level by design. First-timers see the same numbers under "across the Resolved community". The brand never prints ₹0.

4 · Active-case nudge

Dot badge on Cases tab
An above-CTA banner would push the CTA off the visual center — violates rule #1. Badge is one-tap, thumb-zone, no vertical competition. Pulses when <24h to auto-escalate.

5 · Mode toggle

Top-right header · 44pt · icon-only
Binary, visually obvious — labels would steal width from the wordmark.

6 · Pull-to-refresh

Yes — refreshes stats + active case
The orb is the loading cue, reusing the brand mark instead of a generic spinner.

7 · Scroll behavior

Header static · nav fixed · aurora parallax (dark only)
Shrinking the header on an 80px scroll is theatre that costs tap area. Aurora drift at 0.15× — subtle is the whole point.
