Resolved — Home. Mobile (iPhone), 420px content column. Use the Tweaks panel to switch between user states.

UX decisions on this screen

  • Single CTA. "View my cases" lives in the bottom nav; a second button on Home would widen the intent funnel.
  • Stats below capabilities. Numbers only land after the user understands what the product does.
  • Empty state = community stats. A first-time user sees "₹14.2L recovered across users", never "₹0 recovered".
  • Personalization is a top strip. Active-case status lives ABOVE the hero, never inside it — hero is identical for all three user types.
  • Notifications surface on Cases tab. No top banners, no toasts on Home.
  • Pull-to-refresh. Refreshes stats + active case status. The orb is the loading cue.
  • Onboarding hint = subhead. No tooltip on the CTA — kills premium feel.
