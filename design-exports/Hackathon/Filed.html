UX picks, on the screen

Inline rationale at // — UX: in filed-screen.jsx. Both frames run the same component; only the mode prop differs.

Q1 · Celebration

Subtle orb pulse + green chip
Confetti is a category mismatch — this is a legal-adjacent product. Confident exhale, not fireworks.

Q2 · Case ID

Gradient text-clip on the # number only
"Case" stays solid · "#RV-00214" gradient. Names the unique ID without making the noun loud.

Q3 · Node states

Three states — completed · next · pending
"Next" gets a thicker outline + saffron-soft halo. Rejected severity-color-coding — implies court is "scary".

Q4 · Tap a step

All tappable, accordion expand
Brief offered "only completed" — but pending steps are the teaching moment: tap to see exactly what we'd do.

Q5 · Connector line

Solid above completed · dotted below
Past is solid. Future is provisional ("if needed").

Q6 · Callout placement

After the ladder
Ladder = evidence. Callout = conclusion drawn from it. Lead with the work, then the promise.

Q7 · Primary CTA

"See all my cases →"
Natural next step post-filing is the dashboard — not back-to-home.

Q8 · Secondary

"Or file another complaint"
Dashed underline · power-user path · names a real second intent.

Callout microcopy

"You do nothing. We watch for replies and fire the next step the moment it's due."
17 words. "fire" beats "trigger automatically" (action-verb gravity vs tech word); "the moment it's due" is a clock event, not a vague promise.
